# artius.iD SDK Icon Theming System Documentation

## Overview
The artius.iD Android SDK provides comprehensive icon theming capabilities that allow host applications to customize all icons throughout the SDK using a centralized theming system.

## Icon Categories (19 Categories)

### 1. Core UI Icons
- primaryIconColorHex - Main UI icons
- secondaryIconColorHex - Secondary UI elements
- accentIconColorHex - Accent/highlight icons
- disabledIconColorHex - Disabled state icons

### 2. Navigation & Actions
- navigationIconColorHex - Back buttons, navigation arrows
- actionIconColorHex - Action buttons, interactive elements

### 3. Instruction & Feedback
- instructionIconColorHex - Help, info, guidance icons
- warningIconColorHex - Warning indicators
- errorIconColorHex - Error states
- successIconColorHex - Success confirmations

### 4. Document & Verification
- documentIconColorHex - Document type icons
- cameraIconColorHex - Camera controls
- scanIconColorHex - Scanning indicators

### 5. Security & Biometrics
- biometricIconColorHex - Face scan, fingerprint icons
- securityIconColorHex - Security badges, locks
- nfcIconColorHex - NFC scanning icons

### 6. Status Indicators
- statusActiveIconColorHex - Active/enabled states
- statusInactiveIconColorHex - Inactive/disabled states
- statusProcessingIconColorHex - Loading/processing states

### 2. SDK Icon Usage (SDK Internal)

```kotlin
// ThemedIcon Composable - Automatically applies theme colors
@Composable
fun ThemedIcon(
    iconRes: Int,
    category: IconCategory,
    modifier: Modifier = Modifier,
    contentDescription: String? = null
) {
    val iconColor = ThemedIconColors.getColorForCategory(category)
    
    Icon(
        painter = painterResource(id = iconRes),
        contentDescription = contentDescription,
        tint = iconColor,
        modifier = modifier
    )
}

// Usage Examples in SDK Screens
@Composable
fun DocumentSelectionScreen() {
    // Document type icons
    ThemedIcon(
        iconRes = R.drawable.ic_passport,
        category = IconCategory.DOCUMENT,
        contentDescription = "Passport"
    )
    
    // Navigation back button
    ThemedIcon(
        iconRes = R.drawable.ic_arrow_back,
        category = IconCategory.NAVIGATION,
        contentDescription = "Back"
    )
    
    // Success indicator
    ThemedIcon(
        iconRes = R.drawable.ic_check_circle,
        category = IconCategory.SUCCESS,
        contentDescription = "Success"
    )
}
```

### 4. Color Resolution System

```kotlin
object ThemedIconColors {
    @Composable
    fun getColorForCategory(category: IconCategory): Color {
        val iconTheme = LocalEnhancedTheme.current.iconTheme
        
        return when (category) {
            IconCategory.PRIMARY -> Color(parseColor(iconTheme.primaryIconColorHex))
            IconCategory.NAVIGATION -> Color(parseColor(iconTheme.navigationIconColorHex))
            IconCategory.SUCCESS -> Color(parseColor(iconTheme.successIconColorHex))
            IconCategory.ERROR -> Color(parseColor(iconTheme.errorIconColorHex))
            IconCategory.DOCUMENT -> Color(parseColor(iconTheme.documentIconColorHex))
            IconCategory.BIOMETRIC -> Color(parseColor(iconTheme.biometricIconColorHex))
            // ... all other categories
        }
    }
}
```

## Key Benefits for iOS Team

### 1. Centralized Control
- Single configuration point for all icon colors
- No need to modify individual screens
- Consistent theming across entire SDK

### 2. Granular Control
- 19 different icon categories
- Each category can have different colors
- Supports complex branding requirements

### 3. Dynamic Application
- Colors applied at runtime
- No recompilation needed for theme changes
- Instant visual feedback

### 4. Automatic Inheritance
- All SDK screens automatically use themed colors
- New screens inherit theming without additional code
- Backwards compatible with existing implementations

## Real-World Usage Example

```kotlin
// Host App Integration
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        
        // Configure SDK with custom icon theme
        val customTheme = EnhancedSDKThemeConfiguration(
            brandName = "My Banking App",
            iconTheme = SDKIconTheme(
                // Banking app uses gold for primary actions
                primaryIconColorHex = "#FFD700",
                // Security icons are green for trust
                securityIconColorHex = "#00C853",
                // Error states are red
                errorIconColorHex = "#D32F2F",
                // All other categories...
            )
        )
        
        // Initialize SDK
        ArtiusIDSDK.initializeWithEnhancedTheme(
            context = this,
            configuration = sdkConfig,
            enhancedTheme = customTheme
        )
    }
}
```

## Summary

This system ensures that every icon in the SDK (navigation arrows, document icons, success checkmarks, error indicators, etc.) automatically uses the host app's brand colors without requiring individual customization of each screen or component.

The theming system provides:
- 19 distinct icon categories for granular control
- Centralized configuration through SDKIconTheme
- Automatic application across all SDK screens
- Runtime color changes without recompilation
- Consistent branding throughout the verification flow

This approach allows host applications to maintain their brand identity while using the full functionality of the artius.iD SDK.
